# Security policy

**Development-stage warning:** SOAR Desk is not ready for PHI, personally identifying information, Social Security numbers, or other production client data.

## Reporting vulnerabilities
Do **not** publish exploit details or sensitive test data in public issues. Use GitHub's private vulnerability reporting feature if enabled for this repository; otherwise contact the project maintainer privately through an established trusted channel. Do not submit live client files as examples.

## Security assumptions
No data storage, encryption, identity management, backups, or secure file handling has been implemented in the foundation release. No confidentiality, HIPAA compliance, or production readiness claim is made.

## Security release gate
A security threat model, organizational approval, protected key management, encryption of database/files/backups, recovery testing, data retention controls, audit records, dependency review, and independent testing are prerequisites to storing real client data.
